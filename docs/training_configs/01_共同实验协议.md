## 共享预测器和奖励视图

| 项目 | 锁定值 |
|---|---|
| 原始目标 | 两个pActivity预测值均最大化 |
| 优化奖励归一化 | `clip((pActivity - 3.0) / (6.5 - 3.0), 0, 1)` |
| 无效分子奖励 | 0（基线共享oracle视图）；CLOVER内部无效轨迹奖励为 -1 |
| HV归一化区间 | 3.0--10.0 |
| HV参考点 | `[0.0, 0.0]` |
| 指纹接口 | Morgan/ECFP4，radius=2，2048 bits；四预测器的具体手性设置见预测器文档 |
| 质量惩罚 | 不进入原始oracle分数；质量指标在生成后单独计算 |

所有方法必须使用同一批重新训练出的预测器文件。不能给某一方法使用不同预测器或不同奖励阈值。

## 随机性与资源

| 项目 | 锁定值/记录值 |
|---|---|
| Python哈希种子 | 与实验seed一致；底层预训练统一为42 |
