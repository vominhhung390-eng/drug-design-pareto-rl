# 评价指标、统计与论文表格配置

## 单种子评价顺序

```text
generated.csv
  -> evaluation/evaluate_anytime.py
  -> evaluation/evaluate_experiment.py
  -> evaluation/quality_constrained_metrics.py
  -> analysis/compare_v4b_graphpareto_two_pairs_20260827.py
```

Anytime预算固定为1,024、2,048、5,120和10,240。主表只使用10,240预算结果。

## 主生成性能指标

| 指标 | 方向 | 定义要点 |
|---|---:|---|
| Validity | ↑ | 有效RDKit分子占全部提案比例 |
| Uniqueness | ↑ | 有效分子中canonical SMILES唯一比例 |
| Novelty | ↑ | 唯一有效分子不在共同训练集中的比例 |
| Diversity | ↑ | 唯一有效分子的内部ECFP4 Tanimoto多样性 |
| HV | ↑ | 3.0--10.0归一化、参考点 `[0,0]` 的二维hypervolume |
| IGD+ | ↓ | 相对同一靶点对全部方法/种子构成的pooled reference front |
| Pareto size | ↑ | 当前种子非支配分子数量 |
| Dual@6 | ↑ | 两个预测值均≥6.0的比例 |

## 质量约束指标

质量通过定义固定为：

```text
QED >= 0.60
SA <= 4.0
无 PAINS/Brenk structural alert
通过 Lipinski
```

| 指标 | 方向 |
|---|---:|
| Quality pass | ↑ |
| Alert-free | ↑ |
| Scaffold diversity | ↑ |
| QC-HV | ↑ |
| QC-Dual@6 | ↑ |
| QC-Dual@7 | ↑ |
| QC best-min | ↑ |

## 种子统计规则

- 先对每个 `方法 × 靶点对 × seed` 独立计算指标。
- 再对种子42--51计算均值和样本标准差。
- 不允许先合并10个种子的分子再计算Validity、Novelty、HV或Pareto size。
- 配对显著性检验必须按相同seed配对。
- `evaluation/statistical_report.py` 默认bootstrap=10,000、统计seed=2026。

## 论文表格脚本依赖

最终两靶点对表格必须保留以下完整调用链：

```text
analysis/compare_v4b_graphpareto_two_pairs_20260827.py
analysis/compare_v5_all_baselines_two_pairs.py
analysis/build_target_pair_current_metrics.py
analysis/build_main_experiment_metrics.py
evaluation/evaluate_experiment.py
evaluation/evaluate_anytime.py
evaluation/multiobjective_metrics.py
evaluation/quality_constrained_metrics.py
evaluation/statistical_report.py
```

只保留最外层脚本而删除两个被导入模块会导致表格构建失败。

## 统一运行命令

```powershell
pwsh ./scripts/build_paper_tables.ps1
```

精简包不应上传旧的canonical缓存，因此发布前应增加由 `train_smiles_only.txt` 自动生成该缓存的步骤，并修改脚本默认路径。

脚本必须输出：

```text
per_seed_metrics.csv
aggregate_metrics.csv
completion.csv
egfr_vegfr2_igd_reference_front.csv
parp1_brd4_igd_reference_front.csv
all_baselines_summary.md
metadata.json
```

入口会严格检查两组靶点、六种方法、每方法10个种子是否齐全；不齐全时停止，不生成容易误用的残缺主表。输出位于 `results/paper_tables/`，包含两张带方向箭头的Markdown表、逐种子CSV、聚合CSV、两组IGD+参考前沿和metadata。
